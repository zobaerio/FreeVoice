# FreeVoice Privacy

- No Zobaerio backend or hosted website is used.
- Cartesia and OpenAI requests are sent directly from the Android device to those providers.
- API keys are held in application memory for the current session and are not persisted to disk or committed to GitHub.
- Script history is stored locally on the device.
- Audio is saved to the app's Documents/FreeVoice folder when requested, with Android share-sheet support.
- Internet is required for AI generation.

Provider privacy policies and billing terms apply.
